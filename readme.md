# ITCHgram

**A Full-Stack Social Media Application**

## English

### About the Project

ITCHgramm is a personal full-stack web development project focused on building a modern social media platform.

The goal is to develop a functional application where users can create personal profiles, share posts, follow other users, and interact with each other.

The project is being developed step by step, with a focus on backend architecture, database relationships, authentication, security, and modern frontend development.

### Technology Stack

**Frontend**
- React
- JavaScript
- Material UI (MUI)

**Backend**
- Node.js
- Express.js
- MongoDB
- Mongoose
- JSON Web Tokens (JWT)
- bcrypt

### Current Development

The backend is currently under development, including user registration, authentication, profile management, posts, and user-following functionality.

The frontend and additional features will be developed progressively.

ITCHgramm is an educational project and is not yet a finished application.

## Deutsch

### Über das Projekt

ITCHgramm ist ein persönliches Full-Stack-Webentwicklungsprojekt mit dem Ziel, eine moderne Social-Media-Plattform zu entwickeln.

Die Anwendung soll es Nutzern ermöglichen, persönliche Profile zu erstellen, Beiträge zu veröffentlichen, anderen Nutzern zu folgen und miteinander zu interagieren.

Das Projekt wird schrittweise entwickelt. Der Schwerpunkt liegt auf der Backend-Architektur, Datenbankbeziehungen, Authentifizierung, Sicherheit und moderner Frontend-Entwicklung.

### Verwendete Technologien

**Frontend**
- React
- JavaScript
- Material UI (MUI)

**Backend**
- Node.js
- Express.js
- MongoDB
- Mongoose
- JSON Web Tokens (JWT)
- bcrypt

### Aktueller Entwicklungsstand

Das Backend befindet sich derzeit in der Entwicklung. Dazu gehören die Benutzerregistrierung, Authentifizierung, Profilverwaltung, Beiträge und die Funktion zum Folgen anderer Nutzer.

Das Frontend und weitere Funktionen werden schrittweise entwickelt.

ITCHgramm ist ein Lernprojekt und noch keine fertiggestellte Anwendung.
